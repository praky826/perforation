Phase 5 Completion Summary: Per-Hole Feature Extraction (Steps 11-18)

Files Created and Purpose:
step11_subpixel_contour.py implements Step 11. It derives a per-hole midpoint brightness threshold from the backlit crop and runs skimage.measure.find_contours (marching squares) at that level, selecting the largest-area contour and storing the ordered subpixel [x,y] polyline to subpixel_outline.json.
step12_centroid_radius_profile.py implements Step 12. It computes the center via cv2.moments for interior holes or a Kasa circle fit refined by scipy.optimize.least_squares for edge teeth, then samples distance-from-center at 72 fixed 5-degree steps, marking steps with no nearby outline vertex as no-data, saving a RadiusProfile to radius_profile.json.
step13_shape_deviation_descriptor.py implements Step 13. It fits a Fourier series (harmonics 1-4) over valid samples, records the four harmonic magnitudes, mean_radius_um and radius_std_um (converted via microns_per_pixel), and roundness_ratio (interior holes only), writing the ShapeDescriptor into descriptors.json under key shape. It also exposes fit_fourier_series and evaluate_fourier_series for reuse.
step14_boundary_texture_sampling.py implements Step 14. It resamples the outline at fixed physical arc-length spacing, estimates the local tangent, selects the torch crop with the highest local Sobel contrast at each point, and cuts tangent-aligned patches saved under boundary_patches/.
step15_roughness_descriptor.py implements Step 15. It computes Sobel mean/std (skimage.filters.sobel) and GLCM contrast/homogeneity (skimage.feature) per patch, averages across patches, and adds residual_wobble (std of raw radius minus the reused Fourier fit), writing the RoughnessDescriptor under key roughness.
step16_angular_brightness_sampling.py implements Step 16. At each valid angle step it offsets outward onto the paper and bilinearly samples brightness in each torch crop, saving a per-hole table (rows=valid angles, columns=torches) to angular_brightness_table.json.
step17_directional_profile_fitting.py implements Step 17. Per boundary point it solves I=A+u*cos(phi)+v*sin(phi) by linear least squares against torch azimuths from IlluminationGeometry, sums the (u,v) vectors across points, and writes the ShadowDescriptor (strength, direction_deg, per_point_confidence_summary) under key shadow.
step18_composite_signature_assembly.py implements Step 18. It reads the three descriptor blocks and assembles the fixed 14-element vector in COMPOSITE_FIELD_ORDER (NaN placeholder for tooth roundness_ratio), writes the CompositeSignature under key composite, and increments manifest holes_processed.

Backend API Function Signatures Added:
None. Per the development-order rules backend/api.py is built in Phase 9. Stage entry points added: run_step11(session_id, holes, crops), run_step12(session_id, holes, outlines), run_step13(session_id, holes, radius_profiles, outlines, calibration_record), run_step14(session_id, holes, outlines, crops, calibration_record), run_step15(session_id, holes, patches, radius_profiles), run_step16(session_id, holes, radius_profiles, crops, calibration_record), run_step17(session_id, holes, angular_tables, illumination_geometry), run_step18(session_id, holes). All take an optional session_manager and return a hole_id-keyed dict.

Key Data Structures and JSON Formats Used:
Per-hole outputs under holes/<hole_id>/: subpixel_outline.json, radius_profile.json (center_px, angles_deg, distances_px with nulls, valid_mask), angular_brightness_table.json (torch_order, rows), boundary_patches/, and descriptors.json holding keys shape, roughness, shadow, composite. descriptors.json is updated incrementally via a read-modify-write helper so each step only writes its own key. Constants added to pipeline_constants.py: BOUNDARY_SAMPLE_SPACING_UM=20.0, BOUNDARY_PATCH_SIZE_PX=7, GLCM_LEVELS=256, GLCM_DISTANCES=[1], GLCM_ANGLES_DEG=[0.0], PAPER_SAMPLE_OFFSET_UM=60.0, all also exported in get_pipeline_constants_dict.

Ambiguities Encountered and Resolution:
The documents specify that sampling parameters exist but leave exact values as tuning ("e.g. 20 micrometers", "e.g. 5x5 or 7x7") and give no number for the Step 16 paper offset. Chosen values were centralized in pipeline_constants.py rather than hardcoded, obeying the freeze rule. Angle-step validity uses the nearest outline vertex within one angle-step, avoiding a new magic threshold. roundness_ratio is stored as null in descriptors.json but as NaN inside the composite vector, per the frozen plan decision to keep vector length fixed.

Decisions Made Not Explicitly in Documents:
residual_wobble is expressed in pixels (raw radius units), consistent across holes for per-field z-scoring in Step 20. step13 was refactored to expose the full Fourier coefficient vector so step15 reuses the same fit instead of introducing new fitting logic. scipy and scikit-image were installed locally only to verify import resolution; no image or specimen data was created. Verified all eight files import cleanly and contain zero Qt/PySide6 imports; numeric sanity checks on the pure-math helpers (radius profile, Fourier magnitudes, per-point cosine fit) returned correct values.
