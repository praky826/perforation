Phase 6 Completion Summary: Statistical Detection & Output (Steps 19-23)

Files Created and Purpose:
step19_reference_group_construction.py implements Step 19. For each hole it builds the leave-one-out comparison set: every other hole on the same edge when that edge has at least MIN_HOLES_PER_EDGE holes (stratification "edge"), otherwise every other hole on the specimen (stratification "pooled", low_confidence true). The ReferenceGroup is returned in memory (not a separate file) and the pooled holes are written to manifest.low_confidence_holes.
step20_robust_stats_deviation_score.py implements Step 20. Per composite field it computes the group median and MAD (scipy.stats.median_abs_deviation), converts the hole's value to a robust z (0.6745*(v-med)/MAD), and combines them as an L2 norm (summed_z) or, when configured, a MinCovDet Mahalanobis distance, writing the DeviationScore to score.json.
step21_outlier_thresholding.py implements Step 21. It resolves the cutoff (fixed OUTLIER_CUTOFF for summed_z, or the chi-square critical value at MAHALANOBIS_SIGNIFICANCE_LEVEL with degrees of freedom equal to the composite length for mahalanobis), sets is_outlier, and merges the OutlierFlag into score.json under key outlier.
step22_spatial_clustering.py implements Step 22. Within each edge's position-ordered sequence it finds runs of consecutive flagged holes, optionally bridging a single unflagged gap (REGION_MERGE_ENABLED / REGION_MERGE_MAX_GAP), and writes each run as a CandidateRegion (with a bounding polygon of member centroids) to stages/candidate_regions.json.
step23_final_output_generation.py implements Step 23. It draws a score-colored (blue-to-red) marker at each hole on the orientation-normalized overview, outlines each candidate region, writes results/annotated_overview.png, and builds results/results_table.csv (one row per hole with edge, position_index, type, all 14 composite fields, combined_score, is_outlier, threshold_used, low_confidence). It records the image in the manifest and sets session status complete.

Backend API Function Signatures Added:
None. backend/api.py is built in Phase 9. Stage entry points added: run_step19(session_id, holes), run_step20(session_id, holes, composites, reference_groups), run_step21(session_id, holes, deviation_scores), run_step22(session_id, holes, outlier_flags, stamp_frame), run_step23(session_id, holes, overview_image, reference_groups, candidate_regions). All take an optional session_manager.

Key Data Structures and JSON Formats Used:
ReferenceGroup dict: hole_id, comparison_group_ids, stratification, low_confidence. DeviationScore (score.json): per_field_z, combined_score, method, group_median, group_mad. OutlierFlag merged into score.json under key outlier: is_outlier, threshold_used. CandidateRegion (stages/candidate_regions.json): region_id, edge, hole_ids, start_position, end_position, region_coords_px. Final outputs: results/annotated_overview.png and results/results_table.csv. New constants added to pipeline_constants.py: MAHALANOBIS_SIGNIFICANCE_LEVEL=0.025 and REGION_MERGE_ENABLED=True, both also exported in get_pipeline_constants_dict.

Ambiguities Encountered and Resolution:
The document gives the Mahalanobis cutoff only as an example significance ("e.g. 2.5%"); this was frozen as MAHALANOBIS_SIGNIFICANCE_LEVEL=0.025 and the cutoff computed as sqrt(chi2.ppf(0.975, dof)) since combined_score is a distance, not its square. The document does not give an exact region_coords_px construction; the axis-aligned bounding polygon of a run's member hole centroids (in normalized stamp coordinates) is used as the drawable region geometry. A field with zero spread or an all-NaN group (roundness across teeth) yields z=0 rather than infinity; those expected NaN-slice warnings are suppressed around the statistical calls.

Decisions Made Not Explicitly in Documents:
Step 23 uses OpenCV drawing and Python's stdlib csv writer, both explicitly sanctioned by the algorithm document as alternatives to Matplotlib/pandas, avoiding those uninstalled heavy dependencies while staying within the stack. scikit-learn is imported lazily inside the Mahalanobis branch only, so the module loads under the default summed_z method without sklearn installed; the Mahalanobis path also falls back to summed_z if the group is too small or the fit fails. The overview marker radius is derived from image width rather than a fixed constant. Verified all five files compile, import cleanly, contain zero Qt/PySide6 imports, and pass numeric sanity checks (robust z isolates an outlier field, NaN fields give z=0, single-gap run merge toggles correctly, thresholds and color mapping match expectations). No image or specimen data was created.
